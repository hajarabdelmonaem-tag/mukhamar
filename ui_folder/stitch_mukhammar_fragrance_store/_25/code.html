سياسة الخصوصية

١. مقدمة

في "مخمر" (Mukhamar)، نولي اهتماماً بالغاً بخصوصية عملائنا الكرام. تهدف سياسة الخصوصية هذه إلى توضيح كيفية جمعنا واستخدامنا وحمايتنا لمعلوماتك الشخصية عند استخدامك لتطبيقنا. نلتزم التزاماً كاملاً بضمان سرية وأمان بياناتك وفقاً لأعلى معايير الحماية والممارسات الفضلى في قطاع التجزئة الفاخرة.

٢. المعلومات التي نجمعها

نقوم بجمع أنواع مختلفة من المعلومات لتقديم وتطوير خدماتنا بشكل يتناسب مع تطلعاتك:

  • المعلومات الشخصية: مثل الاسم، عنوان البريد الإلكتروني، رقم الهاتف، وعناوين التوصيل التي تقدمها عند إنشاء حساب أو إتمام عملية شراء.
  • بيانات الدفع: يتم معالجة معلومات البطاقات الائتمانية عبر بوابات دفع آمنة ومشفرة، ولا نحتفظ بتفاصيل بطاكقتك الكاملة على خوادمنا.
  • معلومات الاستخدام: بيانات حول كيفية تفاعلك مع التطبيق، مثل المنتجات المفضلة وتاريخ المشتريات، لتقديم توصيات عطرية مخصصة.

٣. كيفية استخدام بياناتك

نستخدم المعلومات التي نجمعها للأغراض التالية:

  • معالجة طلباتك وتوصيل المنتجات الفاخرة إليك بكفاءة.
  • تخصيص تجربة التسوق الخاصة بك واقتراح عطور تناسب ذوقك الرفيع.
  • التواصل معك بخصوص حالة الطلب، التحديثات، والعروض الحصرية.
  • تحسين وتطوير أداء التطبيق وخدمة العملاء.

٤. أمن وحماية البيانات

نتخذ إجراءات أمنية صارمة، فنية وإدارية، لحماية معلوماتك الشخصية من الوصول غير المصرح به، التعديل، أو الإفشاء. نستخدم تقنيات التشفير المتقدمة (SSL) لضمان سرية البيانات المنقولة بين جهازك وخوادمنا. رغم ذلك، نود الإشارة إلى أنه لا توجد وسيلة نقل عبر الإنترنت آمنة بنسبة 100%، ولكننا نبذل قصارى جهدنا لضمان أعلى مستويات الحماية الممكنة.
